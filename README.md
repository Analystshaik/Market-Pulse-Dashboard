# TLT/TBT Client Dashboards — Streamlit Cloud

Production cloud package for five apps:
- TLT Daily
- TLT Weekly
- TBT Daily
- TBT Weekly
- Market Pulse

Start with `DEPLOYMENT_GUIDE.md`.

First deployment:
1. `01_PREPARE_CLOUD.bat`
2. Create an empty GitHub repo
3. `02_GITHUB_FIRST_DEPLOY.bat`
4. Deploy the five app entrypoints in Streamlit Community Cloud

Routine post-EOD update:
- `03_PUSH_CLOUD_UPDATE.bat`
